# ELYTRONSITE

Elytron AI Core - Modern web application built with React, TypeScript, and Vite.

## Features

- Modern React application with TypeScript
- Built with Vite for fast development
- Styled with TailwindCSS
- Component library using shadcn/ui

## Getting Started

### Prerequisites

- Node.js
- Bun or npm

### Installation

```bash
bun install
```

### Development

```bash
bun dev
```

### Build

```bash
bun build
```
